# Jmeh-sindikata Grantpin

## How do I install these formulae?

`brew install jmeh-sindikata/grantpin/<formula>`

Or `brew tap jmeh-sindikata/grantpin` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jmeh-sindikata/grantpin"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
